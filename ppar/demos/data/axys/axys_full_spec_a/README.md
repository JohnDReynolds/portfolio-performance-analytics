# Axys Full-Spec Snapshot A

This packaged snapshot is paired with `axys_full_spec_b` for the
performance-comparison portfolio and security demos.

The data is derived from the Mega-Cap Alpha analytics demo and reshaped into
Axys-style operational files. It includes one portfolio, six monthly periods,
ten mega-cap equities, a cash balance row, and short Treasury bill/note rows so
the workbook has realistic cash, accrued-income, price, position, transaction,
and security-return examples.
