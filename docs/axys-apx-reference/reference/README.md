# Reader Reference

This folder contains the reader-facing Axys/APX reference chapters.

Start with `Chapter_01_Overview.md` for the repository map, evidence rules, and
current blockers. Use `../evidence/` only when you need research provenance, and
use `../contracts/` only when you need implementation-facing ppar contracts or
templates.
