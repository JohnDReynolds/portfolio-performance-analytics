# Work Session Notes

## Current State

The performance comparison XLSX work is now workbook-first. For bundles
generated with `--include-workbook`, reviewers should start with
`report.xlsx`; `report.html` is a browser-friendly view of the same review
model, and CSV files are audit/export artifacts.

The current workbook sheets are:

- `Performance Differences` sheet: portfolio-period return differences, explained
  difference, unexplained difference, status, and comments.
- `Performance Differences` sheet: security-period return differences, including
  explicit no-security-difference rows for changed portfolio periods.
- `Identifiable Causes` sheet: input rows that may explain portfolio differences, with
  `Performance Difference Explained` when ppar has a defensible calculation and
  `Review Guidance` when setup is missing.
- `Other Evidence` sheet: review-only supporting differences.
- `Raw Audit Trail` sheet: full finding-level detail.

Workbook numeric cells are real Excel numbers where possible. Numeric display
uses up to six decimals with trailing zeros suppressed.

## Key Decisions

- Treat `report.xlsx` as the primary reviewer artifact.
- Keep `report.html`, CSV files, and `manifest.json` for browser, audit, export,
  and validation uses.
- Keep `openpyxl` as a regular runtime dependency because XLSX is the primary
  reviewer surface.
- Keep lower-level bundle workbook generation opt-in with `--include-workbook`
  for custom bundle commands.
- Keep the workbook action-oriented: "This is the performance difference, and
  this is what explains it."
- Keep deep diagnostic fields such as `Code` and `Review Rank` in
  the `Raw Audit Trail` sheet, not in the main action sheets.
- Use the same left-side sort fields for the `Identifiable Causes` sheet,
  `Other Evidence` sheet, and `Raw Audit Trail` sheet: `Portfolio`, `From Date`,
  `Thru Date`, `Dataset`, `Source Column`, `Security`.

## Current Implementation Notes

- `ppar/performance_comparison/report.py` still builds the report tables and
  workbook sheet DataFrames.
- `ppar/performance_comparison/workbook.py` owns XLSX presentation mechanics:
  sheet metadata, required workbook headers, workbook writing/styling,
  numeric/date formatting, and workbook artifact validation.
- Generated bundle `README.md` files now use role-based sections:
  `Primary Review Artifact`, `Secondary Review Views`, `Recommended Review
  Order`, and `Audit/Export Files`.
- `ppar.performance_comparison.cli.report_bundle` prints the workbook path
  before the HTML path when `--include-workbook` is used.
